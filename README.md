# Phân tích kinh tế tài chính dự án năng lượng tái tạo

Repository phát triển mô hình Excel `PTKTTC_Ver1.xlsx` dùng chung cho dự án điện gió và điện mặt trời.

Quy ước trong mô hình:

- Số liệu phải nhập: chữ màu đỏ.
- Kết quả tính toán: chữ màu xanh blue.
- Thông số và kết quả quan trọng: chữ đậm.
